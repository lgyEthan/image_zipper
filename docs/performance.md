# 0.1.3 용량·속도 검증

2026-10-22, 동일한 로컬 Apple silicon Mac과 Python 3.12 환경에서 이전 코드와 수정 코드를 비교했습니다. 디스크 캐시가 적용된 합성 사진·도표를 사용했습니다. 시간은 대표 실행값이며 실제 파일·기기·코덱에 따라 달라집니다. 보편적인 속도 향상 배율을 뜻하지 않습니다.

## 최대 2 MB 결과

동일한 입력 PNG를 JPEG 4:4:4로 변환합니다. 프리셋 품질 95, 최소 품질 90, 상한은 정확히 2,000,000바이트입니다.

| 원본 픽셀 | 이전 출력 | 수정 출력 | 상한 사용률 | 수정 DPI |
|---|---:|---:|---:|---:|
| 1400 × 933 | 1,308,215 B | 1,982,983 B | 99.1% | 300 |
| 1500 × 1000 | 1,549,898 B | 1,984,030 B | 99.2% | 298.8 |
| 1600 × 1067 | 1,816,228 B | 1,999,400 B | 100.0% 미만 | 295.5 |

기존에는 품질 95에서 일찍 반환했습니다. 수정 버전은 품질을 더 높이고 필요한 경우 해상도를 조금 조절합니다. 사용하지 않은 공간을 패딩으로 채운 결과가 아닙니다.

## 압축 시간

3600 × 2400 입력 PNG, 상한 2,097,152바이트(2 MiB), 최소 품질 90입니다. 기존 버전의 단위와 동일하게 비교했습니다.

| 작업 | 이전 | 수정 | 수정 출력 / 상한 |
|---|---:|---:|---:|
| PNG 축소 | 2.24초 | 2.02초 | 99.4% |
| 이미지 → PDF 병합·압축 | 10.32초 | 2.42초 | 99.8% |

PDF 구조 분석·디코딩·축소 픽셀을 재사용하고, 사진에 대한 중복 DEFLATE를 줄였습니다. 시험 압축 후 같은 설정으로 저장할 때는 임시 결과를 재사용합니다. 해당 재사용은 인코더가 다시 호출되지 않는 회귀 검사로 검증합니다.

## 로딩과 추정

- 27.5 MB PNG의 하드링크 1,000개: 첫 행 약 0.003초, 전체 목록 약 0.97초, 선택 파일 미리보기 약 1.50초.
- 가장 긴 UI 타이머 간격 약 0.027초. 파일 로딩 중 전체 시험 압축 호출은 0회입니다.
- 압축 방식이 다른 입력 파일의 바이트 수 대신 원본 해상도 표본을 사용해 추정을 보정합니다. 표본 밖의 콘텐츠 때문에 오차는 남으며, 실제 저장 크기는 항상 전체 출력 바이트로 확인합니다.

이미 원본/무손실/최고 품질 결과가 상한보다 작은 파일은 더 작게 저장됩니다. 파일을 부풀리거나 원본보다 확대하지 않습니다. 픽셀·품질 단계가 불연속적이므로 모든 입력에서 98.5% 이상의 사용률을 보장하지는 않습니다.

재현 명령: `python scripts/benchmark_loading.py input.png --count 1000`, `python scripts/benchmark_compression.py input.png --format pdf --max-mb 2.097152 --repeat 3`.
